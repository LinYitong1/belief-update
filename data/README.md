# Data Directory

Raw data, processed datasets, and analysis outputs for the Belief Updating Project.

---

## Primary Datasets

| File | Description |
|------|-------------|
| `df.csv` | Experimental dataset (novel data) |
| `s.csv` | Stengard replication dataset |
| `demographic.csv` | Participant demographics |

---

## Processed Files (RDS)

Generated by analysis pipeline:

| File | Source Script | Content |
|------|---------------|---------|
| `parameter_dt.rds` | `01_simulate_parameters.R` | Prior parameter samples (experimental) |
| `parameter_dt_s.rds` | `01_simulate_parameters.R` | Prior parameter samples (Stengard) |
| `prediction_dt.rds` | `02_generate_predictions.R` | Model predictions (experimental) |
| `prediction_dt_s.rds` | `02_generate_predictions.R` | Model predictions (Stengard) |
| `Simulate_Summary_dt.rds` | `03_summary_stats.R` | Simulated summary statistics (experimental) |
| `Simulate_Summary_dts.rds` | `03_summary_stats.R` | Simulated summary statistics (Stengard) |
| `Human_Summary_dt.rds` | `03_summary_stats.R` | Human data summary statistics (experimental) |
| `Human_Summary_dts.rds` | `03_summary_stats.R` | Human data summary statistics (Stengard) |
| `posterior_long.rds` | `04_abcrf_individual_inference.R` | Individual model probabilities (experimental) |
| `posterior_long_s.rds` | `04_abcrf_individual_inference.R` | Individual model probabilities (Stengard) |

---

## Data Dictionary

**Key variables:**

| Variable | Description | Values |
|----------|-------------|--------|
| `subject` | Participant ID | String |
| `format` | Presentation format | "frequency", "probability" |
| `BR`, `HR`, `FAR` | Task parameters (base rate, hit rate, false alarm rate) | 0-1 |
| `true_posterior` | Normative Bayesian posterior | 0-1 |
| `response` | Participant's estimate | 0-1 or 0-100 |
| `trial` | Trial number | Integer |

---

## Loading Data

```r
# Raw data
df <- read.csv("data/df.csv")
s  <- read.csv("data/s.csv")

# Processed data
params <- readRDS("data/parameter_dt.rds")
sims   <- readRDS("data/Simulate_Summary_dt.rds")
human  <- readRDS("data/Human_Summary_dt.rds")
post   <- readRDS("data/posterior_long.rds")
```
